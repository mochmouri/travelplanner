## Frontend Aesthetics Rules
- Avoid AI Defaults: Explicitly do NOT use Inter, Roboto, or Arial. Do not use generic purple/blue gradients.
- Design System: Use specific component libraries like [shadcn/ui](https://shadcn.com) or [Radix primitives](https://radix-ui.com) rather than raw CSS. 
- Typography: Opt for distinctive, premium fonts (e.g., Geist, Playfair Display).
- Icons: Only use [Lucide-React](https://lucide.dev) or Phosphor icons. Never use emojis for UI elements.
- Spacing: Enforce a strict "swiss-style" grid with ample whitespace. Avoid cramped layouts.
- Motion: Prioritize CSS-only animations for high-impact moments like page loads over scattered micro-interactions.
- Placeholders: Use `[COPY NEEDED]` markers instead of generating marketing "lorem ipsum" or generic "realistic" content.
